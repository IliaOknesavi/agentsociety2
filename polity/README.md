# polity

Наш код поверх AgentSociety 2: сравнение форм власти на одной популяции агентов. Файлы каркаса лежат в остальных папках репозитория и здесь не меняются.

## Модель по подписке: Claude или Codex

AgentSociety 2 обращается к модели по HTTP. `llm/subscription_shim.py` это локальный сервер, который принимает такой запрос и выполняет его через CLI с подпиской: `claude -p` (Claude Code) или `codex app-server` (встраиваемый режим Codex: один постоянный процесс, запросы по JSON-RPC). Ключ API не нужен.

```bash
# из корня репозитория, после uv sync --package agentsociety2
polity/run_with_subscription.sh packages/agentsociety2/examples/games/02_public_goods.py
MODEL=sonnet polity/run_with_subscription.sh packages/agentsociety2/examples/games/02_public_goods.py
MODEL=codex polity/run_with_subscription.sh packages/agentsociety2/examples/games/02_public_goods.py
```

Скрипт поднимает прокладку, задаёт каркасу адрес и имя модели, запускает сценарий в `polity/runs/` и в конце печатает счётчики.

| `MODEL` | Куда идёт запрос |
|---|---|
| `haiku`, `sonnet`, `opus` | Claude через `claude -p` |
| `codex` | Codex через `codex app-server`, модель по умолчанию |
| `codex/<имя модели>` | Codex с указанной моделью |

- **Кэш.** Ответы хранятся в `polity/.cache/llm.sqlite` по ключу из модели и полного текста запроса. Повтор прогона с теми же промптами не вызывает модель и даёт те же ответы.
- **Счётчики.** `GET /stats`: настоящие вызовы, попадания в кэш, токены, цена по тарифу API (Claude её сообщает, Codex нет; по подписке деньги не списываются). Каждый настоящий вызов пишется строкой в `polity/.cache/calls.jsonl`.
- **Проверка без модели.** `python polity/llm/subscription_shim.py --selftest`.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `MODEL` | `haiku` | модель для сценария |
| `PORT` | `18765` | порт прокладки |
| `SHIM_MAX_CALLS` | без предела | предел настоящих вызовов модели за запуск прокладки |
| `SHIM_CONCURRENCY` | `8` | сколько процессов CLI идёт одновременно |
| `SHIM_EFFORT` | `low` | усилие рассуждения модели |
| `SHIM_PROMPTS` | выключено | путь к файлу, куда писать полный текст запросов |
| `SHIM_CODEX_HOME` | не задана | отдельная папка настроек Codex для симуляций, см. ниже |
| `SHIM_CODEX_MODE` | `app-server` | `exec`: запасной путь, отдельный процесс `codex exec` на каждый вопрос |
| `SHIM_CACHE`, `SHIM_LOG` | `polity/.cache/` | где лежат кэш и журнал |

## Что CLI добавляет к запросу от себя

Оба CLI это программы для разработки, и к каждому запросу они дописывают свой служебный текст. Прокладка отключает всё, что отключается, и запускает CLI из пустой папки.

| | Claude | Codex |
|---|---|---|
| Системный промпт | заменяется нашим целиком | заменяется нашим (`baseInstructions` треда) |
| Остаток сверху | около 990 токенов: почта аккаунта, дата, имя модели | около 9 500 токенов: описания встроенных инструментов, личный `~/.codex/AGENTS.md`, блоки о навыках и мультиагентности |
| Время вызова | 8-11 секунд | 8-26 секунд |
| Встроенные инструменты | отключены полностью | часть остаётся и флагами не убирается: запуск команд в песочнице только для чтения, запуск субагентов |

Личный `AGENTS.md` у каждого свой, поэтому на Codex с домашними настройками агенты у разных людей получают разный текст. Чтобы этого не было, заведите Codex отдельную чистую папку настроек и войдите в ней один раз:

```bash
CODEX_HOME=~/.codex-polity codex login
SHIM_CODEX_HOME=~/.codex-polity MODEL=codex polity/run_with_subscription.sh сценарий.py
```

Общие ограничения:

- вероятностей вариантов, температуры и зерна нет; воспроизводимость даёт кэш;
- эмбеддингов нет: кэш переводов в маршрутизаторе каркаса работает по точному совпадению текста запроса.
