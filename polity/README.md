# polity

Наш код поверх AgentSociety 2: сравнение форм власти на одной популяции агентов. Файлы каркаса лежат в остальных папках репозитория и здесь не меняются.

## Модель: Claude по подписке

AgentSociety 2 обращается к модели по HTTP. `llm/claude_p_shim.py` это локальный сервер, который принимает такой запрос и выполняет его через `claude -p` (Claude Code в неинтерактивном режиме), то есть по подписке, без ключа API.

```bash
# из корня репозитория, после uv sync --package agentsociety2
polity/run_with_claude.sh packages/agentsociety2/examples/games/02_public_goods.py
MODEL=sonnet polity/run_with_claude.sh packages/agentsociety2/examples/games/02_public_goods.py
```

Скрипт поднимает прокладку, задаёт каркасу адрес и имя модели, запускает сценарий в `polity/runs/` и в конце печатает счётчики.

- **Кэш.** Ответы хранятся в `polity/.cache/llm.sqlite` по ключу из модели и полного текста запроса. Повтор прогона с теми же промптами не вызывает модель и даёт те же ответы.
- **Счётчики.** `GET /stats`: настоящие вызовы, попадания в кэш, токены, цена по тарифу API (по подписке деньги не списываются). Каждый настоящий вызов пишется строкой в `polity/.cache/calls.jsonl`.
- **Проверка без модели.** `python polity/llm/claude_p_shim.py --selftest`.

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `MODEL` | `haiku` | модель для сценария: `haiku`, `sonnet` |
| `PORT` | `18765` | порт прокладки |
| `SHIM_MAX_CALLS` | без предела | предел настоящих вызовов модели за запуск прокладки |
| `SHIM_CONCURRENCY` | `8` | сколько процессов `claude -p` идёт одновременно |
| `SHIM_PROMPTS` | выключено | путь к файлу, куда писать полный текст запросов |
| `SHIM_CACHE`, `SHIM_LOG` | `polity/.cache/` | где лежат кэш и журнал |

Ограничения `claude -p`:

- вероятностей вариантов, температуры и зерна нет; воспроизводимость даёт кэш;
- к каждому запросу Claude Code добавляет около 990 токенов своего контекста (почта аккаунта, дата, имя модели). Чтобы туда не попадал индекс заметок Claude Code, прокладка запускает его из пустой папки;
- эмбеддингов нет: кэш переводов в маршрутизаторе каркаса работает по точному совпадению текста запроса.
