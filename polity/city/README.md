# Город на рельсах

Приложение для запуска и просмотра прогонов города: сообщество жителей живёт под одной из трёх форм власти.
Правила мира одинаковы для всех, форма власти меняет одно: у кого право решать.

## Запуск

```bash
.venv/bin/python polity/city/app.py
```

Экран откроется на http://127.0.0.1:8790. Если модель доступна только через локальный прокси, приложение
запускается с переменной `HTTPS_PROXY`: прокладка и CLI модели берут прокси из его окружения. Слева задаётся город и запускается прогон, справа четыре вкладки:
ход месяца, жители, итоги прогона, сравнение форм.

Жители бывают двух видов:

- **по правилам**: без модели, прогон считается сразу. Нужны, чтобы проверять мир и экран; выводов о формах
  власти по ним не делается;
- **на модели**: прогон идёт в AgentSociety 2 через прокладку к подписке (`polity/llm/subscription_shim.py`).
  Каркас поднимается около минуты, дальше запись пополняется после каждой волны, экран показывает её сам.

То же без экрана:

```bash
MODEL=chatgpt/gpt-6.2-sol polity/run_with_subscription.sh polity/city/run_city.py --form council --residents 12 --months 4
```

## Как устроен месяц

Месяц идёт тремя волнами, одна волна это один шаг общества в каркасе и один вызов модели на жителя.

| Волна | Что делает житель |
|---|---|
| план | делит свободные часы месяца: лента, близкие, разбор закона (4 часа); остальное уходит на отдых и быт |
| обсуждение | читает столько записей, на сколько хватило часов ленты, пишет, комментирует, шлёт письма и монеты |
| решение | те, у кого право решать, голосуют; остальные могут писать и переводить деньги |

После третьей волны среда считает голоса, применяет закон и проводит деньги месяца: заработок, взнос в фонд,
доходность фонда, дивиденд поровну. Житель, которому в волне нечего читать и не о чём решать, модель не зовёт.

## Что задано правилами и что из них получается

| Задано | Получается и измеряется |
|---|---|
| свободные часы жителя и цена занятий в часах | сколько времени уходит на политику, явка |
| лента: порядок по свежести, отклику, подписчикам и подпискам | кого читают, доля просмотров у решающих |
| расчёт последствий закона, доступный каждому за 4 часа | кто разобрался в законе перед решением |
| переводы монет и личные сообщения | оплаченная поддержка, деньги решающим |
| право решать: все жители, выборный совет, совет по жребию | какие законы приняты |
| злодеи розданы случайно, место в городе им не задаётся | попали ли они в решающие, платили ли |

Законов десять: пять убыточных для типичного жителя (выгода сейчас и убыток потом, обещание автора расходится
с расчётом, оплата решающих), четыре выгодных (затраты сейчас, выгода потом) и один спорный о перераспределении.
Убыточность не записана в законе, её считает среда: экономика прогоняется на год вперёд с законом и без него.
В повестке убыточные и выгодные чередуются.

## Где что лежит

| Файл | Что в нём |
|---|---|
| `packages/agentsociety2/agentsociety2/contrib/env/city_rails/world.py` | мир: правила, законы, деньги, запись и метрики; от каркаса не зависит |
| `.../city_rails/env.py` | среда `CityRailsEnv` для AgentSociety 2: `month_view` и `submit_actions` |
| `.../city_rails/resident.py` | промпт жителя, список действий, разбор ответа модели |
| `packages/agentsociety2/agentsociety2/contrib/agent/resident_agent.py` | агент `ResidentAgent`: один вызов модели на волну |
| `polity/city/run_city.py` | прогон в каркасе из командной строки |
| `polity/city/app.py`, `polity/city/web/index.html` | приложение |
| `polity/city/runs/` | записи прогонов, в git не попадают |

Самопроверка мира без модели: `.venv/bin/python packages/agentsociety2/agentsociety2/contrib/env/city_rails/world.py`.

## Чего пока нет

- Жители условные: возраст, занятие и характер розданы случайно. Двойники Twin-2K-500 не подключены.
- Терпение жителя в промпт не входит: модель его не различает, способ раздачи не выбран.
- Продажа страницы и реклама в ленте не сделаны; оплаченная запись и взятка складываются из перевода и письма.
- Законы вносит среда по готовой повестке, жители законов не предлагают.
- Продолжить прерванный прогон нельзя, он запускается заново.
