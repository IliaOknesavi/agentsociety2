# Симуляция форм власти

Приложение для запуска и просмотра симуляций города: сообщество жителей живёт под одной из четырёх форм власти.
Правила мира одинаковы для всех, форма власти меняет одно: у кого право решать.

## Запуск

```bash
.venv/bin/python polity/city/app.py
```

Экран откроется на http://127.0.0.1:8790. Если модель доступна только через локальный прокси, приложение
запускается с переменной `HTTPS_PROXY`: прокладка и CLI модели берут прокси из его окружения.

Приложение состоит из отдельных сцен:

| Сцена | Что на ней |
|---|---|
| Запуски | запуски по городам, кнопки «копия» и «удалить» |
| Новый запуск | город с предпросмотром жителей и повестки, формы власти (можно несколько), порог, злодеи, правила или модель, расчёт цены до запуска |
| Запуск: месяцы | список законов, круг жителей (решающие ближе к центру, закраска по мнению о законе, обводка по голосу), лента, письма, переводы, мысли |
| Карточка закона | слова автора и расчёт города, голоса решающих и мнение всех жителей, таблица по каждому жителю |
| Карточка жителя | деньги по месяцам, связи, мысли, переписка, ход за ходом с текстом промпта и действиями |
| Запуск: выборы | округа, кандидаты с программами, кампания и дебаты, голоса по турам |
| Запуск: итоги, цена | показатели запуска; расход по месяцам, волнам и жителям |
| Сравнение | выбранные запуски в одной таблице |

Жители бывают двух видов:

- **по правилам**: без модели, прогон считается сразу. Нужны, чтобы проверять мир и экран; выводов о формах
  власти по ним не делается;
- **на модели**: прогон идёт в AgentSociety 2 через прокладку к подписке (`polity/llm/subscription_shim.py`).
  Каркас поднимается около минуты, дальше запись пополняется после каждой волны, экран показывает её сам.

То же без экрана:

```bash
MODEL=chatgpt/gpt-6.2-sol polity/run_with_subscription.sh polity/city/run_city.py --form council --residents 12 --months 4
```

## Один и тот же город

Город задают источник жителей, их число и зерно. У людей, злодеев, повестки и жребия свои потоки случайности от
одного зерна: люди и законы не зависят от формы власти, доли злодеев и хода прогона, а злодеи при большей доле
включают злодеев при меньшей. Поэтому прогоны одного города можно сравнивать.

## Откуда жители

- **условные**: возраст, занятие и характер розданы случайно по зерну;
- **из опроса Twin-2K-500**: у жителя его собственные возраст, занятость, доход семьи, образование, взгляды и выбор
  в игре на делёж; имя условное. Выгрузка делается один раз интерпретатором polity-sim:

```bash
cd ~/aist/polity-sim && .venv/bin/python ~/aist/agentsociety2/polity/city/export_twins.py
```

## Как устроен месяц

Месяц идёт тремя волнами, одна волна это один шаг общества в каркасе и один вызов модели на жителя.

| Волна | Что делает житель |
|---|---|
| план | делит свободные часы месяца: лента, близкие, разбор закона (4 часа); остальное уходит на отдых и быт |
| обсуждение | читает столько записей, на сколько хватило часов ленты, пишет, комментирует, шлёт письма и монеты |
| решение | те, у кого право решать, голосуют; каждый житель втайне отвечает, за он или против; остальные действия те же |

На каждом ходу житель записывает мысль про себя: её не видит никто из жителей, она остаётся в записи прогона.

После третьей волны среда считает голоса, применяет закон и проводит деньги месяца: заработок, взнос в фонд,
доходность фонда, оплата городских служб из фонда, дивиденд из излишка сверх запаса на службы. Если фонда на
службы не хватает, недостачу жители платят сами. Житель, которому в волне нечего читать и не о чём решать, модель не зовёт.

## Что задано правилами и что из них получается

| Задано | Получается и измеряется |
|---|---|
| свободные часы жителя и цена занятий в часах | сколько времени уходит на политику, явка |
| лента: порядок по свежести, отклику, подписчикам и подпискам | кого читают, доля просмотров у решающих |
| расчёт последствий закона, доступный каждому за 4 часа | кто разобрался в законе перед решением |
| по выбору: город рассылает общий расчёт закона всем жителям | меняет ли это решения; правило одно для всех форм |
| переводы монет и личные сообщения | оплаченная поддержка, деньги решающим |
| зал тех, кто решает, при совете и жребии: канал, который пишут и читают только жители с правом голоса; чтение стоит часов | обсуждают ли решающие закон между собой и сколько реплик успевают прочесть |
| право решать: все жители, все жители с отзывным делегированием голоса, выборный совет, совет по жребию | какие законы приняты |
| злодеи розданы случайно, место в городе им не задаётся | попали ли они в решающие, платили ли |

Законов десять: выгода сейчас и убыток потом (разовая выплата, отмена взноса), обещание автора расходится с
расчётом (поддержка мастерских, частный управляющий, освобождение владельцев от взноса), вложения (оборудование,
дорога, больница) и перераспределение (взнос по доходу, пособие должникам). Ярлыка «выгоден» или «убыточен» у
закона нет: среда прогоняет экономику на год и на три года с законом и без него и показывает жителю раздельно
деньги на руки и долю фонда. Плохим в итогах считается только закон, плохой по обоим счётам.

## Выборы совета

Город делится на округа, от округа один член совета на шесть месяцев. Перед первым месяцем и затем раз в
полгода идёт раунд выборов: выдвижение с программой, кампания, дебаты, голосование; если в округе никто не
набрал больше половины голосов, двое первых идут во второй тур. Член совета получает зарплату из фонда и тратит
на совет часы месяца. Тяга к власти у жителя из опроса считается по его ответам о ценностях.

Самопроверка мира без модели: `.venv/bin/python packages/agentsociety2/agentsociety2/contrib/env/city_rails/world.py`.

## Чего пока нет

- Жители из опроса Twin-2K-500 получают выжимку своих ответов (около 2,7 тысячи знаков из 24 тысяч анкеты),
  поэтому замер сходства взглядов на полной анкете к таким жителям не относится.
- Терпение жителя в промпт не входит: модель его не различает, способ раздачи не выбран.
- Продажа страницы и реклама в ленте не сделаны; оплаченная запись и взятка складываются из перевода и письма.
- Законы вносит среда по готовой повестке, жители законов не предлагают.
- Продолжить прерванный запуск нельзя, он запускается заново.
